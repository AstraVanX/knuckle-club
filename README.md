# Knuckle Club

A responsive woodcut comic website with star ribbons, a star cursor and a small workshop sound palette.

A fictional garage demonstration: sample contact details and local-only repair notes. Original artwork and fonts are served from this site; tiny sound effects are embedded for prompt playback.

Sound effects are rendered and composed from [Earshot](https://github.com/Leonxlnx/earshot), MIT, copyright 2026 Leon Lin. Full audio and font license notices are retained in index.html.
